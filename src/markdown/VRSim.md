# Vikings Rise Simulator

I used to develop overly complicated [spreadsheets](https://docs.google.com/spreadsheets/d/1K58qtLoV3qQs6SRVvbTYkXMHe9huhFVeghFTwJ4SCB8/edit?usp=sharing) to simulate the mobile game Vikings Rise. Given two setups, troop numbers and etc it could simulate the trades each side would get to reasonable accuracy. Since some setups cost cost thousands if you payed it was quite useful and the sheet usually had a couple people using it at any given time. As part of this through testing I learned a lot of the games mechanics and one of my first projects was using this to create my own combat simulator in Java. Being in my first semester of college I was in the deep but through a lot of googling I made a working program. It was able to simulate ~1 million rounds of combat a second which was pretty nice. I created a badly vibe coded web hosted version. I was happy it had some users but needless to say it was pretty awful and buggy so I started writing a new and improved version in C++. Bad updates to the game though lead to me quitting but I enjoyed the time spent. On the good side I received some free merch from the company and an interview on their youtube channel.
